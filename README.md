# Network Device Manager

A Java-based application for managing, monitoring, and configuring network devices.

## Features
- Track network devices and their statuses
- Manage device IP addresses and configurations
- Simple and structured Java architecture

## Requirements
- Java Development Kit (JDK) 11 or higher

## How to Run
1. Clone the repository:
   git clone https://github.com/kechli/network-device-manager.git
2. Open the project in your favorite IDE (VS Code, IntelliJ, Eclipse).
3. Run the main class located in `src/`.
